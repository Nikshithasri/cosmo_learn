# 🚀 Cosmo Learn

**Cosmo Learn** is an interactive, space-themed learning platform designed to make education more engaging, fun, and accessible for students.

The platform combines **learning, games, quizzes, and interactive activities** in a space-inspired environment where students can explore different subjects and concepts through a gamified experience.

---

## 🌌 About the Project

Cosmo Learn creates a fun learning environment where students can explore educational content through a **space-themed interface**.

The platform is designed for students from **Grade 1 to Grade 10**, with learning content and activities organized according to their grade level.

Students can explore different learning areas, learn concepts, play educational games, and test their knowledge through quizzes.

---

## ✨ Key Features

* 🌌 **Interactive Space-Themed UI**
* 🎓 **Grade-wise Learning** — Grades 1 to 10
* 🪐 **Planet-based Subject Navigation**
* 💻 **Coding Planet** for programming-related learning
* 📚 **Concept-based Learning**
* 🎮 **Educational Games**
* 🧠 **Interactive Quizzes**
* 📊 **Learning Progress**
* 🧑‍🎓 **Student-friendly Interface**
* 📱 **Responsive and Modern Design**

---



## 🪐 Learning Experience

The learning journey is organized around different planets and learning areas.

Students can:

1. Select their grade.
2. Explore available learning concepts.
3. Learn through interactive content.
4. Practice concepts through educational games.
5. Take quizzes to test their understanding.
6. Progress through different learning levels.

---

## 💻 Coding Planet

One of the major learning areas is the **Coding Planet**, where students can learn programming concepts progressively.

The learning path introduces programming concepts according to the student's level, making programming easier and more engaging for beginners.

Topics can include:

* 🧩 Basic Programming Concepts
* 🔢 Variables and Data Types
* 🔄 Loops
* 🔀 If-Else Conditions
* 🐍 Python Basics
* 💡 Problem Solving

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Nikshithasri/cosmo_learn.git
```

### 2. Navigate to the Project

```bash
cd cosmo_learn
```

### 3. Install Dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### 4. Start the Development Server

Using npm:

```bash
npm run dev
```

Or using Bun:

```bash
bun run dev
```

The application will be available at the local development URL provided by Vite.
